Fault-Tolerance Features

ONLINE — Wi-Fi and MQTT connected.

DEGRADED — Wi-Fi connected, MQTT unavailable.

OFFLINE — Wi-Fi unavailable; readings are buffered locally.

Recovery — queued readings are published when MQTT reconnects.

The dashboard uses incoming data freshness to detect interruptions. The OLED on the ESP32 displays the actual device network state.
